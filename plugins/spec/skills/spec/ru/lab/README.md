# Стенд

> В этот репозиторий `runs/` не перенесены (10 МБ): данные прогонов из таблиц ниже лежат в metarepo-test3, `playbooks/rutalk/lab/runs/`. Новые прогоны пишутся в `runs/` локально и в git не попадают.

Стенд нужен, чтобы менять промпты плейбука и мерить эффект: писатель пишет тексты по заданиям, ревьюер из [../review/](../review/reviewer-prompt.md) их проверяет, отдельный агент сверяет тексты с заданием. Здесь же лежат данные всех измерений, на которых построен плейбук.

## Что здесь

| Путь | Что это |
|---|---|
| `briefs.py` → `briefs.jsonl` | 32 задания: 20 для настройки (`dev`, `d01`–`d20`) и 12 отложенных (`test`, `t01`–`t12`). У каждого есть жанр, текст задания для писателя и контекст для ревьюера: жанр, читатель, задача |
| `lab.py` | Прогоны: `write`, `revise`, `review`, `check`, `score` |
| `brief_check.py` | Измерение шага 1: вопросы автору и доля будущих пробелов, которые они покрывают |
| `prompts/` | Промежуточные версии промпта писателя: `baseline` — без указаний о стиле, `ref` — одна строка со ссылкой на книги, `v1`–`v4`, `v3min`. Итоговая версия — [../writing-a-text.md](../writing-a-text.md) |
| `runs/<прогон>/` | Данные прогона: `texts/` — тексты, `reviews/` — отчёты ревьюера, `checks/` — сверка с заданием, `meta/` — модель, стоимость, длина, `writer-prompt.md` — промпт писателя, с которым шёл прогон |

## Команды

Запускать из этой папки. Нужен `claude` (Claude Code CLI).

```bash
python3 briefs.py                                         # пересобрать briefs.jsonl после правки заданий

python3 lab.py write  --run r1 --split dev                # писатель: по умолчанию ../writing-a-text.md, Sonnet, medium
python3 lab.py write  --run r1-h --split dev --model haiku
python3 lab.py write  --run r1-base --split dev --prompt prompts/baseline.md
python3 lab.py review --run r1 --split dev                # ревьюер: Opus, каталог в системном промпте
python3 lab.py check  --run r1 --split dev                # сверка с заданием: Sonnet
python3 lab.py score  --run r1 --split dev --vs baseline  # сводка → runs/r1/score-vs-baseline.md

python3 lab.py revise --run r1-rev --source r1            # одна правка по находкам ревью, затем review и check

python3 brief_check.py ask && python3 brief_check.py judge && python3 brief_check.py report
```

Прогон можно прервать и запустить снова с тем же `--run`: готовые тексты, отчёты и сверки пропускаются (`--force` — перезапустить).

## Как устроено измерение

- **Писатель изолирован.** Он запускается с `--safe-mode`, без инструментов, из пустой папки `sandbox/`. Системный промпт — только промпт писателя, в сообщении — только задание.
- **Ревьюер — как в плейбуке.** Промпт и каталог из `../review/`, разрешены только `Read` и `python3 text_scan.py`, отчёт в JSON.
- **Сверка с заданием.** Промпт [../checking-facts.md](../checking-facts.md), модель Sonnet high.
- **Основная метрика** — находок ревью на текст. Дополнительные — взвешенно по серьёзности, выдуманные факты на текст и тексты без находок.

## Правила

- **Подбирайте промпт по `dev`, итог мерьте на `test` один раз.** Иначе правки подгоняются под задания и цифры перестают говорить о чужих текстах. Итоговый промпт собран по остаткам `dev`, поэтому его цифры на `dev` завышены, а честная оценка — `test`.
- **Мерьте минимум на двух моделях:** Sonnet и Haiku, 40 текстов на вариант.
- **Шум ревьюера:** ±0,1–0,2 находки на текст на 20 текстах. При повторной проверке тех же текстов воспроизводится около половины находок, поэтому разница меньше этого — не улучшение.
- **Смотрите на систематические остатки.** Это коды, которые повторяются у разных моделей и в разных прогонах, — их разбирайте по текстам отчётов, а не по одной цифре.

## Известный артефакт

Сессии Claude Code получают email пользователя. Поэтому писатель иногда подписывает текст названием компании из его домена, например «Vivid», хотя в задании названия нет. В рабочей среде писателя этого не будет. Сверка такие названия не считает выдумкой: см. `CHECK_LAB_NOTE` в `lab.py`.

## Прогоны в `runs/`

Во всех прогонах ревьюер — Opus. Писатель Sonnet или Haiku пишет с effort medium.

| Прогон | Писатель | Промпт | Задания |
|---|---|---|---|
| `baseline`, `h-baseline` | Sonnet, Haiku | `prompts/baseline.md` | dev |
| `ref`, `h-ref` | Sonnet, Haiku | `prompts/ref.md` — одна строка со ссылкой на книги | dev |
| `v1`…`v4`, `v3min`, `h-v1`…`h-v4`, `h-v3min` | Sonnet, Haiku | `prompts/v*.md` | dev |
| `final`, `h-final` | Sonnet, Haiku | итоговый промпт | dev |
| `test-baseline`, `test-h-baseline`, `test-final`, `test-h-final` | Sonnet, Haiku | без промпта и итоговый | test |
| `o-baseline`, `o-final` | Opus, effort medium | без промпта и итоговый | все 32 |
| `ox-baseline`, `ox-final` | Opus, effort xhigh | без промпта и итоговый | все 32 |
| `ox-rev1` | Opus xhigh | одна правка `ox-final` по находкам ревью, затем свежее ревью всех 32 | все 32 |
| `ref-rr`, `h-v1-rr`, `ox-final-rr` | — | повторное ревью тех же текстов: контроль шума ревьюера | — |
| `brief-check` | Opus medium | вопросы автору (`*.q.json`) и покрытие пробелов (`*.j.json`) | все 32 |

## Стоимость

- **Ревью:** около $0,28 на текст с прогретым кэшем, первый вызов около $0,8.
- **Писатель:** Sonnet около $0,01 на текст, Opus medium около $0,03, Opus xhigh с промптом около $0,20.
- **Сверка с заданием и проверка задания:** по $0,01–0,02.
- **Прогон одного варианта** на 40 текстах (Sonnet и Haiku, dev) стоит около $12.
